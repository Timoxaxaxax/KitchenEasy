# «Что готовим?» — полностью локальное PWA

## Архитектура и приватность
- Нет backend, API, аккаунтов, серверной базы данных и синхронизации.
- База рецептов и все иллюстрации входят в комплект приложения.
- Настройки, продукты, техника, избранное, отложенные и скрытые рецепты хранятся на устройстве в IndexedDB.
- При недоступности IndexedDB используется резервное сохранение в localStorage.
- Резервную копию пользовательских данных можно экспортировать в JSON и импортировать на другом устройстве.
- Внешние шрифты и сторонние сетевые зависимости удалены.
- Service Worker предварительно кеширует приложение, базу и все 500 иллюстраций.

## Запуск для тестирования
Для браузерного PWA Service Worker требует защищённый контекст: HTTPS или localhost. Это нужно только для первоначального открытия/установки и не означает наличие backend.

1. Распакуйте архив.
2. Откройте терминал в папке проекта.
3. Выполните `python -m http.server 8080`.
4. Откройте `http://localhost:8080`.

Для установки на телефоны через браузер PWA обычно нужно один раз открыть по HTTPS. После установки и первичного кеширования приложение работает офлайн. Самостоятельный HTTPS-хостинг — это только раздача статических файлов, не сервер приложения и не хранилище пользовательских данных.

## Использование без какого-либо хостинга
Если требуется вообще не использовать HTTPS-хостинг даже для первоначальной установки, проект нужно упаковать в нативную оболочку:
- Android: APK с ресурсами внутри приложения;
- iOS/iPadOS: сборка и подпись приложения для установки;
- Windows/macOS/Linux: desktop-пакет.
Один и тот же PWA-проект можно использовать как основу таких сборок, но сами установочные пакеты требуют отдельной сборки под платформы.

## Функции
- Бюджет 500–10 000 ₽, порции, время, сложность и кухня.
- Выбор продуктов и кухонной техники.
- Свайпы: влево — скрыть, вправо — понравилось, вниз — отложить.
- Подробная карточка рецепта, граммовки и шаги.
- Избранное и отложенные рецепты.
- Экспорт/импорт пользовательских данных.

## Ограничения каталога
В комплекте 500 структурированных карточек, автоматически сформированных из комбинаций базовых рецептур, кухонь и вариантов ингредиентов. Это демонстрационный каталог, а не редакционно проверенная кулинарная энциклопедия. Граммовки, шаги и цены ориентировочные; изображения — локальные SVG-иллюстрации, а не фотографии готовых блюд. Проверяйте готовность мяса и рыбы перед употреблением.

## Сброс
В разделе «Моя кухня» есть функция очистки пользовательских данных на текущем устройстве. Она не удаляет встроенную базу рецептов.
